# Rkeb — branded Android demo

Updated prerelease with the project's own Rkeb logo:

- Rkeb home-screen/app-drawer icon at all Android densities.
- Adaptive and round launcher variants with a cream background.
- Rkeb splash screen instead of the generic Capacitor artwork.
- Android version code 2, version name `0.1.0-demo.2`.

Download **app-debug.apk**, open it on Android 7.0+ and install/update Rkeb. Choose **Essayer sans compte** for the demo.

The APK build and signature verification passed. Physical-phone installation and launcher appearance have not been verified. This remains a debug-signed prototype with simulated GPS/SOS and demo behavior, not a production service.
